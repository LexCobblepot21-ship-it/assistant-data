# assistant-data
dépot servant a communiquer avec Aicha et ceux qui participeront

## Le projet
Un assistant qui connaît les métadonnées d'une base SQL, pour
1. migrer des traitements SAS/SQL vers KNIME ;
2. faire du text-to-SQL et générer des rapports.

## Contenu
- `livrables/synthese-strategie-migration.md` : synthèse de la stratégie de migration.
- `livrables/avis-databricks.md` : avis sur l'usage de Databricks.
- `documents/` : document Word de faisabilité et plan d'action (usage interne).
